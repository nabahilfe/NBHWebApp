# Initial Data

Dcumentation of the initial data that is generated for this project on startup

## User

### A standard System Administrator is generated with the following data

- Name: System Administrator
- email: webmaster@nabahilfe.eu

Set yor password by registering wit the email address above. You will receive a code you need for the registration process. 
This user has all permissions and is used for the initial setup of the system. 

This initail Setup generates also the required Administrator role and assigns it to the user.

Both entitis, the user and the role, are not editable nor deletable.
